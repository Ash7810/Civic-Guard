# CivicGuard — Road Damage Segmentation System

Automated pothole and road damage detection using YOLOv8, 
served as a REST API via FastAPI.

## What it does
- Takes road images as input
- Runs YOLOv8 segmentation to detect and classify damage
- Returns annotated results via FastAPI endpoint

## Stack
`Python` `YOLOv8` `FastAPI` `Computer Vision`
